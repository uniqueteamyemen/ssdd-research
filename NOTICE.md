# Provenance notice

The canonical SSDD v1.2 source documents and the Python engine reference were supplied by the repository owner and are preserved here once each for review and provenance.

The gem5 simulator itself is not copied into this repository. `simulation/gem5/` and `scripts/` contain only SSDD-specific workload/configuration material intended to run against a separately obtained gem5 checkout under gem5's own license.

The retained Rust ledger reference was written only for a narrow cross-language comparison described in `docs/validation/prehardware-results.md`. It is not an official SSDD runtime implementation.
